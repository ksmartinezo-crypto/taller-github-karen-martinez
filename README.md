# Taller GitHub - Karen Martínez

## Descripción

Este repositorio fue creado como parte del taller individual de GitHub del área de Algoritmos y Programación.

## Proyecto

El proyecto consiste en una calculadora sencilla realizada en Python.

La calculadora permite realizar:

- Suma
- Resta
- Multiplicación
- División

## Organización

El repositorio contiene:

- Una carpeta llamada proyecto.
- Una carpeta llamada documentacion.
- Un archivo README.md.
